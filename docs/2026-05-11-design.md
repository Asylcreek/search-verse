# SearchVerse - Design Specification

**Date:** 2026-05-11
**Status:** Draft
**Author:** Brainstorming session

---

## Overview

A focused web application and API whose sole purpose is to allow users to search for Bible verses by content across multiple translations, and to compare a known verse across translations side by side.

### Core Principles

- **API-first**: The backend is the product. The web UI is a first-class consumer of the same API any third party would use.
- **Cross-translation**: Search results span all selected translations simultaneously. No per-translation silo.
- **Copyright-transparent**: Every verse response includes copyright attribution. The product never implies ownership of source material.
- **Legally grounded**: Bible text is sourced from api.bible under a licensed plan, stored offline per Section 11 of their ToS, and refreshed every 30 days.

---

## Two Modes

### Mode 1 — Search

The user remembers a fragment of a verse and wants to find the source. They type a partial phrase or keyword; the API returns all matching verses across all selected translations, ranked by relevance.

**Example:** User types *"love is patient"* → results include `1COR.13.4` from KJV, NLT, AMP, and any other active translations.

### Mode 2 — Compare

The user knows the exact verse reference and wants to read it across multiple translations. They provide a reference (e.g. `JHN.3.16`) and the API returns the verse text from every selected translation.

## Data Model

```sql
translations
  id              TEXT PRIMARY KEY  -- api.bible bibleId
  abbreviation    TEXT NOT NULL     -- "KJV", "NLT", etc.
  name            TEXT NOT NULL
  language        TEXT NOT NULL     -- ISO 639-3
  copyright       TEXT
  last_synced_at  TIMESTAMPTZ

books
  id              TEXT PRIMARY KEY  -- "GEN", "MRK", "JHN"
  name            TEXT NOT NULL
  testament       TEXT NOT NULL     -- "OT" | "NT"
  position        INT NOT NULL      -- canonical order (1-66)

verses
  id              TEXT NOT NULL     -- api.bible verseId e.g. "JHN.3.16"
  translation_id  TEXT NOT NULL REFERENCES translations(id)
  book_id         TEXT NOT NULL REFERENCES books(id)
  chapter         INT NOT NULL
  verse           INT NOT NULL
  text            TEXT NOT NULL
  text_search     TSVECTOR          -- GIN indexed, auto-generated from text
  PRIMARY KEY (id, translation_id)

user_translations
  user_id         TEXT NOT NULL
  translation_id  TEXT NOT NULL REFERENCES translations(id)
  added_at        TIMESTAMPTZ
  PRIMARY KEY (user_id, translation_id)
```

Cross-translation search runs as a single SQL query across the `verses` table filtered by `translation_id = ANY(...)`, with no joins at search time.

## API

**Base URL:** `https://api.searchverse.app/v1`

**Authentication:** `Authorization: Bearer <api_key>`

### Endpoints

```
GET  /translations              List all available translations
GET  /translations/:id          Get single translation metadata
GET  /search                    Keyword search across translations
GET  /verses/:reference         Compare a verse across translations
```

### GET /search

**Query parameters:**

| Parameter     | Type   | Default    | Description                          |
|---------------|--------|------------|--------------------------------------|
| `q`           | string | required   | Search query                         |
| `translations`| string | `KJV`      | Comma-separated translation IDs      |
| `limit`       | int    | `20`       | Results per page                     |
| `offset`      | int    | `0`        | Pagination offset                    |

**Response:**

```json
{
  "query": "love is patient",
  "total": 84,
  "results": [
    {
      "reference": "1COR.13.4",
      "translation": "NLT",
      "book": "1 Corinthians",
      "chapter": 13,
      "verse": 4,
      "text": "Love is patient and kind...",
      "copyright": "Scripture quotations marked (NLT) are taken from the Holy Bible, New Living Translation, © 1996, 2004, 2015 by Tyndale House Foundation. Used by permission."
    },
    {
      "reference": "1COR.13.4",
      "translation": "KJV",
      "book": "1 Corinthians",
      "chapter": 13,
      "verse": 4,
      "text": "Charity suffereth long, and is kind...",
      "copyright": "King James Version. Public Domain."
    }
  ]
}
```

One result per verse-per-translation match. Same verse appearing in three translations produces three results.

## Data Ingestion

The ingestion pipeline is a NestJS CLI command that:

1. Calls `GET /bibles` on api.bible to confirm active licensed translations
2. For each translation, walks `books → chapters → verses`
3. Upserts all verse text into PostgreSQL
4. Updates `last_synced_at` on each translation

A `@nestjs/schedule` cron job triggers a refresh every 30 days per the api.bible ToS Section 11 requirement. If api.bible removes or modifies content, the refresh propagates the change within 24 hours via an update check endpoint.

## Content Licensing

Bible text served by this API is licensed through api.bible under an active subscription plan. All copyrighted translations (AMP, AMPC, NLT, TPT, MSG, ERV) are accessed under Third Party IP agreements facilitated through api.bible. KJV is public domain.

Copyright attribution is included inline on every verse result. The product does not claim ownership of any translation content.
